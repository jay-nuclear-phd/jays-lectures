# 윤해담 작가 홈페이지

에세이스트 윤해담의 소개와 책을 보여 주는 웹사이트입니다.
`AI 문맹탈출` 4강 실습에서 터미널 AI와 함께 만든 예시이며, 윤해담과 책들은 가상의 인물과 작품입니다.

## 무엇이 들어 있나요

- `index.html`: 첫 화면 (소개, 신간, 책 목록, 모임, 연락)
- `book.html`: 책 읽기 화면 (오른쪽 목차, 본문 찾기, 읽은 만큼 표시)
- `content/about.md`: 작가 소개 글
- `content/books.json`: 책 목록 (제목, 연도, 소개, 표지 색)
- `books/책이름/book.md`: 책 원고. 그림은 같은 폴더의 `img/`에

## 새 책을 올리는 법

1. `books/` 안에 새 폴더를 만들고 원고를 `book.md`로 저장한다
2. `content/books.json`에 책 정보를 한 줄 추가한다
3. 커밋하고 푸시하면 1~2분 뒤 사이트에 반영된다

## 원고 쓰는 규칙

- 책 제목은 `#`, 꼭지 제목은 `##` (오른쪽 목차는 `##`로 만들어진다)
- 그림 아래 줄에 `*기울임*`으로 쓴 글은 그림 설명이 된다
